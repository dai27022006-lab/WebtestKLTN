## 4. Tóm Tắt Nhanh Để Đưa Vào Nơi Làm Việc AI Agent

### Những "Mảnh Ghép Vàng" Nên Bốc Ra Dùng (Đợt 1 → Đợt 4)
1. **Bố cục không rập khuôn:** Bento `1+2` (`Exploreist`), Staggered Grid (`Aurax`/`Archinex`), Grid zic-zac CSS `:nth-of-type(3n+...)` (`Dinevo`), Sticky 2 cột (`Misiom`/`IT-Infinite`), Dark/Light `data-bs-theme` đổi cả logo SVG (`Exploreist` + `Archinex`).
2. **Typography sạch không cắt dấu tiếng Việt:** Zero-pin ink-fill bằng `background-clip: text` dùng CSS token (`Aurax`), tự tách dòng chờ `document.fonts.ready` + `padding-bottom: 0.16em` (`Misiom`/`Archinex`).
3. **Chiều sâu & Reveal chạy GPU:** Progressive bottom blur 8 lớp (`Aurax`), ma trận clip-path 3×3 / 4×3 (`Misiom`/`Dinevo`/`Schon`), Panel pin-scale `0.8 -> 1` có cleanup riêng (`GridTech`), Card khoét góc + 2-image CSS blur swap (`GridTech index-2`).
4. **Tương tác chuột & vật lý thông minh:** Preview bám chuột `gsap.quickTo` / `rAF` (`IT-Infinite`/`Aurax`), GPU FLIP Case Study Expand click-to-open (`Misiom`), mưa thẻ vật lý `Matter.js` dùng 2 `IntersectionObserver` + ngưỡng kéo vs bấm (`Schon`), nút Progress `conic-gradient`/SVG ẩn thông minh trên mobile (`Antra`/`Archinex`).

### 8 Cổng Chặn Lỗi QA Chung Cả 4 Đợt
1. Cấm preloader giả `1–4s` hoặc chạy lặp ở trang con.
2. Cấm lazy-load JS `threshold: 0.3` và `fade-anim` trễ (`delay >= 0.25s`, `top 85%`) gây nháy khung xám / khoảng trắng chết khi cuộn nhanh.
3. Cấm ghép CSS hardcode màu light theme sang dark theme (`GridTech .text_invert-2` đen kịt trên nền tối).
4. Cấm `ScrollTrigger.getAll().kill()` trong `matchMedia` cleanup; luôn null-check mọi element (`#cursor`, button).
5. Cấm `setInterval` bên trong `mousemove` (`Schon`) và cấm hover làm biến mất tiêu đề item đang định click (`IT-Infinite`).
6. Cấm nạp trùng/thừa thư viện (`Swiper` + `Owl`, `SplitText` + `SplitType`, 4 GSAP plugin thừa của `Dinevo`).
7. Luôn dọn custom cursor lúc cuộn (`elementFromPoint`), khóa hover trong `(hover: hover) and (pointer: fine)` và tôn trọng `prefers-reduced-motion`.
8. Sạch 100% nội dung mẫu trước khi bàn giao (xóa `Lorem ipsum`, lỗi chính tả `cloud-ktchen`/`SKINCRE`/`servive-01.jpg`/`ISO Developer`, lặp feature pricing và testimonial copy đúp).
